# Typing Entrepreneur

A gamified typing trainer built in Unity (C#) for my BSc Computer Science Dissertation at Cardiff University. A study with 15 participants found that the gamified version significantly improved typing speed compared with a non-gamified version. Achieved a Distinction.

## How to Play (Windows)
1. Download `Typing-Entrepreneur-Windows.zip` from the latest release
2. Unzip it and run `Typing Entrepreneur.exe`
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**

## Features
1. Idle Game Mechanics
2. Real-time Typing Tracking with Stats
3. Game Design Choices Modelled after Octalysis Framework
